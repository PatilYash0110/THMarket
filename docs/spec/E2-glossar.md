| Begriff | Bedeutung |
|---|---|
| Audit-Log | Chronologisches, unveränderliches Protokoll aller vom Admin-Bereich ausgehenden Aktionen. |
| In-App-Guthaben | Virtuelles, nicht auszahlbares echtes Geld darstellendes Guthaben pro Nutzerkonto (`balanceCents`), nutzbar als Zahlungsmodus beim Kauf. |
| Inserat | Ein von einem Studenten eingestelltes Verkaufsangebot. |
| Konversation | Chat-Thread zwischen genau zwei Nutzern, gebunden an ein Inserat. |
| Meldung (Report) | Von einem Nutzer eingereichter Hinweis auf ein unangemessenes Inserat oder einen unangemessenen Nutzer, zur Bearbeitung durch einen Admin. |
| Mock-Zahlung | Simulierte Zahlung ohne echten Geldfluss, ausgelöst über fest hinterlegte Testkartennummern. |
| Rolle | Legt fest, welchen Bereich der Nutzer nach dem Login sieht: `STUDENT` (Marktplatz) oder `ADMIN` (Verwaltungsbereich). |
| Sitzung (Session) | Nach erfolgreichem Login angelegter Zugriffstoken (JWT), der Rolle und Identität des Nutzers für weitere Anfragen trägt. |
| Sofortkauf | Vom Verkäufer aktivierbare Option; wenn aktiv, zeigt das Inserat einen „Kaufen"-Button, sonst nur „Anbieter kontaktieren". |
| Sonstiges | Sammel-Kategorie für Inserate, die keiner der übrigen festen Kategorien zugeordnet werden können. |
| Verifizierung | Bestätigung der THM-E-Mail-Adresse über einen per Mail zugestellten, zeitlich begrenzten Link; Voraussetzung für den ersten Login. |
