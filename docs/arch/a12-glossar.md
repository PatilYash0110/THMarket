# 12. Glossar

| Begriff | Bedeutung |
| :--- | :--- |
| **Inserat** | Von einem Nutzer erstellte Anzeige für einen Artikel. |
| **Entwurf (ENTWURF)** | Noch nicht veröffentlichtes Inserat. |
| **Campus** | Standort der THM (Gießen, Friedberg, Wetzlar) als Filterkriterium. |
| **KI-Beschreibung** | Von Google Gemini generierter Beschreibungsentwurf aus Bildern. |
| **In-App-Guthaben** | Simulierter Kontostand eines Nutzers für Mock-Zahlungen. |
| **Simulation (Zahlungsmodus)** | Kauf ohne jeglichen Geldfluss. |
| **Audit-Log** | Protokoll aller Admin-Maßnahmen. |
| **EXIF** | In Bildern eingebettete Metadaten (u. a. GPS); werden beim Upload entfernt. |
| **JWT** | JSON Web Token zur Authentifizierung. |
| **SPA** | Single Page Application (React-Frontend / UI Shell). |
| **API Edge** | Eingangsschicht des Backends (Controller, Validierung, Guards, Rate-Limiting). |
| **Persistence** | Datenzugriffsschicht über Prisma. |
| **Prisma** | ORM für den typsicheren Datenbankzugriff. |
| **Socket.io** | Bibliothek für Echtzeit-Kommunikation über WebSockets. |
| **Blackbox** | Baustein nur mit Schnittstellen/Verhalten, ohne innere Details. |
| **Whitebox** | Baustein mit seinen inneren Strukturen und Unterbausteinen. |
| **Verfeinerungsebene** | Detaillierungsgrad der Bausteinsicht (0, 1, 2). |
| **Mock** | Nachbildung einer Funktion ohne echte externe Anbindung. |
| **Rate-Limiting** | Drosselung der Anfragehäufigkeit gegen Missbrauch. |
| **DSGVO** | Datenschutz-Grundverordnung. |
